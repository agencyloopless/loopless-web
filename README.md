# Loopless Agency · Landing

Landing one-page del asistente de WhatsApp de Loopless Agency.

Es una web estática: un solo archivo, `index.html`, sin dependencias ni paso de compilación.

## Publicar en Netlify

- Build command: (vacío)
- Publish directory: `/` (la raíz del repositorio)

## Editar

- Enlace de Calendly: busca `calendly.com/agencyloopless/30min` en `index.html`.
- WhatsApp y email: busca `wa.me/34637685900` y `agencyloopless@gmail.com`.
- Textos de las preguntas frecuentes: array `faqs` al final del archivo.
- Cálculo de la calculadora: función `calc()` al final del archivo (el `0.4` es el porcentaje de clientes que habrían reservado).
